## B01. 가입·동의·연령

- 일반 가입 username 필수 불일치는 서버 생성 내부 식별자/publicId와 이메일 로그인 계약으로 해결. username=email 주입 금지.
- S256 intent·EXCHANGE_SESSION·멱등성·응답 유실 복구 방향을 유지. 미정 nextAction/이메일 proof/기기 세션·오류 details는 기존 [프론트 회신](frontend-contract-reply-2026-09-14.md)에 따라 마무리.
- 회원가입은 만 15세 이상. 일반·소셜·웹·구버전 우회 방지와 기존 회원 처리 필요. 나이·과거 동의를 임의 생성하지 않음.
- NOTICE는 개인정보 동의 이벤트와 분리. 목적별 필요한 안내·동의 및 문서 실패·버전 변경·선택 거부 처리 유지. 광고·이벤트 홍보 푸시가 없으므로 그 동의를 신규 필수로 추가하지 않음.
- 비회원 전체에 만 15세 제한을 적용하지 않으므로 비회원/아동 위치 동의 설계가 여전히 필요. 회원 전용 consent API로 대체 금지.

인수: 일반/소셜/웹·구버전, 15세 경계, UNKNOWN, 문서 실패/변경, intent·exchange 응답 유실, 동일키/변경키, 다른 provider 계정 복구 차단.

## B02. 30일 탈퇴 유예·복구·파기

1. 신청 성공 시 서버 신청 시각과 복구 마감(정확히 30일 후)을 기록하고 프로필/본인 콘텐츠를 즉시 숨김. 일반 접근을 중단하되 필요한 제한 본인 인증·상태 조회·명시 복구 경로 제공.
2. 로그인/재인증만으로 복구 금지. `탈퇴 취소하고 복구하기` 요청에 최근 본인 인증·대상 계정 확인·멱등 및 상태 검증 적용. 읽기 전용 receipt로 복구/취소/로그인 허용 금지.
3. 복구 시 유예에 따른 임시 숨김만 해제. 탈퇴 전 계정/콘텐츠 공개 설정 유지, 비공개·null 보존. 별도 제재·개별 삭제 콘텐츠 복구 금지.
4. 마감 이후 복구와 삭제 작업 경합을 원자적으로 처리. 정책 상태(유예/취소/최종 삭제 진입)와 작업 상태(대기/재시도/완료)를 구분하는 enum/OpenAPI 제안. 기존 ACCEPTED를 유예 종료나 전체 삭제 완료로 해석하지 않음.
5. 계정·본인 게시물·레시피·댓글·원본/변환본/썸네일·게시 장소·계정 연결 추천 기록 삭제. 관계·타인 콘텐츠 연결 처리, 검색/캐시·백업 재삭제도 검증.
6. 탈퇴 이력에 이메일/전화 등 불필요한 원문 복제 금지. 복구에 필요한 최소 상태와 승인된 보관 예외를 분리. 문의·신고·동의 증거·법적 예외의 범위/근거/기간은 별도 회신.
7. 기존 7일 receipt는 30일 유예를 포괄하지 못함. 사전 보안 저장→요청 원칙은 유지하되 조회 수명·갱신/분실·복구 후 폐기·기존 DELETE 호환을 다시 명세. 구버전 탈퇴 경로를 막지 않되 30일 정책 안내와 일치시킴.
8. 개별 게시물 삭제는 유예 없이 즉시 진행. 계정 복구가 삭제한 콘텐츠를 부활시키지 않음. 파일/CDN/백업의 물리 파기 완료 시간은 검증 후 안내.

인수: 신청 즉시 모든 공개 경로/검색/목록·직접 미디어 숨김, 30일 전/정각/후 복구, 동시에 복구/삭제, 로그인만 한 경우, 응답 유실·오프라인·receipt 만료, 실패 재시도, 비공개/null 복원, 합성 잔존표·백업 복원 재삭제. 원래 5분 서명 URL 잔여 효력이 즉시 숨김 정책과 양립하는지 운영 확인 필요. 정책만으로 직접 URL 보호 완료 주장 금지.

## B03. 공개 식별자·미디어·콘텐츠 권리

publicId 전환·endpoint별 명시 opt-in·엄격 parser·기존 링크 종료·계정 범위 캐시를 유지합니다. 이메일 공개 DTO/외부 seed 제거와 서버 식별자 전환을 구분합니다. #33의 Y/N/null 및 조회 권한은 유지하고 수정 생략은 기존 값 유지. 변경하지 않은 공개 상태를 재전송하지 않음.

mediaId/variant/contentVersion, URL 무변형, GET/Range, 제한된 재인가, 캐시 정리·오리진 보호를 완성해 주세요. 탈퇴/차단/권한 상실의 기존 URL 잔여 효력과 즉시 접근 중단 보장 수준을 명세해야 합니다. 미디어 TTL을 개인정보 보관기간으로 쓰지 않습니다.

콘텐츠는 서비스 제공/표시/검색/추천 및 필요한 변환에 사용. 외부 광고·홍보에는 별도 허락. 신고·제재 시 사유/이의신청 방법을 안내하고 긴급 피해에는 임시조치 후 안내하는 처리 흐름 필요. 외부 허락·제재 통지를 구현 없이 완료로 표시하지 않음.

인수: 소유자/친구/타인/차단/비로그인 × 공개 계정/비공개 계정 × Y/N/null, 계정 전환·옛 링크·isGuest flag 우회, 영상 seek/만료·404·원본/썸네일/CDN 직접 접근.

## B04. 회원·비회원 현재 위치와 이력 미보관

- 회원/비회원 모두 위치 권한 허용 시 현재 위치 탐색 제공, 로그인 강제 없음. 필요한 서비스 안내·동의/연령별 절차는 OS 권한과 별도.
- 비회원의 최소 증거/식별·중지/철회·앱 재설치·로그인 전환 계약 제안. 만 15세 회원 제한을 비회원 위치 처리 면제로 해석하지 않음.
- DEVICE/MAP_CENTER/NONE 분리. 현재 위치는 탐색 처리에 필요한 동안만 사용하고 원시 행·로그·스냅샷·큐·분석에 이력으로 남기지 않음. 기존 fp_377 좌표 저장/cleanup도 수정. 임시 메모리·타임아웃·취소 후 잔존 시점을 명세.
- 수동 지도 및 비위치 검색 유지. 계정 PAUSED/WITHDRAWN과 기기 OS 상태 분리, 늦은 ACTIVE/권한 확대 차단 등 기존 revision 방안 유지. 비회원에도 제한 방향 요청의 안전한 적용 설계.
- 게시물의 직접 선택 장소는 게시물 삭제 시까지 보관하며 기기 좌표 자동 복제 금지.
- 이용·제공사실 확인자료는 원시 좌표 이력과 구분해 적용/최소 항목/기간 검토. 외부 지도 공급자의 처리까지 미보관으로 단정하지 않음.

인수: 비회원 현재 위치·수동 검색, OS 권한 거부/해제/재허용, 계정 철회/다른 기기/지연 응답, 원시 좌표의 DB/로그/큐 잔존, SDK·Geocoding·Directions 실제 전송 및 중지.
