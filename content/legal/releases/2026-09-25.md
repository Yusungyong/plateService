# 이용약관 최초 공개 범위

운영자는 검증된 정책·기능의 즉시 적용을 승인했다. 기존 회원의 명시적 수락은 신규 가입·30일 탈퇴·제재 UI와 독립적으로 제공한다.

- 이용약관 2026-09-25: 현재 무료 서비스와 계정 삭제 동작 기준. 공개일/시행일 2026-09-25. 개별 회원에게는 명시적 동의 시부터 적용. 과거 추정·묵시 동의·미동의 계정 자동 제한 없음.
- 신규 15세 가입 정책·30일 복구·자동 전체 파기 미시행. 코드와 다르게 해당 기능을 약속하지 않는다.
- 개인정보 안내 2026-09-25-correction: 실제 동의 원장 처리 항목·계약 관리 목적·운영 DB 계정 삭제 시 cascade 정리·이메일 권리 창구를 보완. 정식 개인정보 처리방침 완성이나 별도 개인정보 동의가 아니다. 백업/외부 계약 정보 미확정은 공개적으로 구분한다.
- 웹 다운로드 원문과 백엔드 V26의 문서 body는 UTF-8 바이트 단위 SHA-256을 일치시킨다. 과거 아카이브는 변경하지 않는다.
- 이전 회원 앱은 가입 전용 disabled catalog를 계속 사용하므로 잘못된 신규 가입 전환 없음. 새 회원 화면은 별도 member-consent-catalog만 사용한다.

백엔드 기준: 206e7f4, ProfileService의 즉시 계정 삭제 및 V25의 동의 원장 cascade. 신규 가입·위치/보관·외부 계약·30일 삭제 후속은 #36에서 추적한다.
