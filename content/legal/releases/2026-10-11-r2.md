# 2026-10-11 개인정보 안내 정정·보완

개인 운영자와 AWS 결제 화면의 공급자 Amazon Web Services Korea LLC를 운영자 답변 및 공식 AWS 안내로 확인했다. 현재 서버/앱 소스에 있는 프로필 변경·로그인·이메일 인증·일부 좌표 요청 자료 처리 항목을 보완하고 개인정보 보호법의 최소 처리·동의 구분·방침 공개·파기·권리 행사 조문을 연결한다. Firebase 설치 식별자의 삭제 API 호출과 호출 후 최대180일을 구분하고 SendGrid37일을 전체 자료의 상한처럼 안내한 문구를 정정한다.

새 개인정보 안내 버전은2026-10-11-r2, 공개일·시행일은2026-10-11이다. 원문과 HTML 및 앱 패킷의 이전 버전은 보존한다. 이용약관·가입 동의 catalog, 과거 동의 기록, 앱/서버 런타임과 DB는 변경하지 않는다. 신규 수집·위치 동의·국외 이전 적법성 전체를 완료했다고 주장하지 않는다.

연락처 검증·게시 권한 부여, 일반 프로필 이력30일·상세 로그인 기록90일 삭제는 후속 구현이며 이번 문안에 완료된 것으로 게시하지 않는다. 외부 국가·기간/재위탁과 위치 신고·동의 정비도 후속 작업이다.
