적용 범위
- 회원: 회원 찾기/이상 징후를 분리, 검색 목록에서 선택하면 옆에 상세와 가능한 조치 표시.
  검색 API는 최대 20명 응답. 전체 회원 목록이나 전체 건수로 오해하지 않도록 안내.
  계정/권한 전환 시 이전 상세와 늦은 응답 제거. 세션 종료 사유·권한·버전 확인 유지.
- 피드: 사진 게시물을 상태별로 찾고, 신고 항목을 강조. 선택 후 상세 패널에서 사진·신고 검토 및 조치.
  신고 필터는 현재 서버 페이지에 한정. 영상 관리 기능을 새로 제공하지 않음.
- 제철 음식: 목록 중심 화면, 선택 즉시 상세 패널로 편집. 저장 오류·충돌 안내를 패널 안에 표시.
  미저장 확인, 저장 중 이탈 방지, 삭제 확인, 닫은 뒤 선택 버튼 포커스 복귀.
- 입점 신청: 대기/보류/승인/거절 빠른 필터, 드문 상세 필터 접기, 불필요한 체크박스 제거.
- 매장: 노출 상태별 찾기, 매장 이름에서 요약 패널 열기, 정보 편집·삭제 확인 연결.
- 문의: 상태별 조회, 불러온 목록 안에서 검색, 선택한 문의의 상세·답변만 표시.
- FAQ: 목록과 상세를 구분하고 편집할 때 편집기 표시. 게시 상태 필터는 불러온 목록 기준.
  다른 항목/필터 전환 시 미저장 확인, 지연된 상세와 필터 응답 보호, 편집 대상 ID 고정.
- 대시보드: 오늘/7일/30일 빠른 조회, 권한별 관련 업무 링크, 모바일 지표 두 열,
  긴 기간 차트 가로 스크롤·날짜·범례 유지. 0값의 최소 막대 높이 제거.
- 공통 상세 패널: 접힌 설정 안의 숨은 입력을 포커스 대상에서 제외, native 삭제 대화상자 우선 처리.
