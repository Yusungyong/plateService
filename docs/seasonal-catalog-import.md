# 공용 제철 식재료 이미지 관리

Backend: Yusungyong/plateAppServer#48. Admin: #1.

1. SEASONAL_MANAGE 권한이 있는 관리자 계정으로 로그인한다.
2. 제철 큐레이션 상단의 `앱 식재료 가져오기`를 누른다.
3. 전체 상태 목록에서 음식을 선택하고 이미지를 업로드한 후 저장한다.
4. 앱 식재료의 이미지가 갱신된다. 이미지 변경을 위해 별도 발행할 필요는 없다.

가져오기는 POST /api/admin/seasonal-curations/import-foods를 호출한다.
공개 식재료 중 미연결 항목만 로그인한 관리자의 초안으로 추가하며 재실행해도 중복 생성하지 않는다.
기존 식재료 원본의 작성 기록과 공개 상태는 그대로 유지한다.
운영에는 백엔드 API 배포 후 이 관리자 빌드를 배포해야 한다.
