# API 오류 발생 계정·메뉴 표시

Backend: Yusungyong/plateAppServer#175 (V54), issue #174. App: Yusungyong/plateApp2#33. Closes plateService#59.

API 구조 관리 → 오류 API 선택 → **계정·메뉴별 발생 기록 보기**. 관리자가 누를 때만 최신 50건을 조회한다. 계정, 요청 시작 화면, 오류 상태, 플랫폼, 요청 시작(기기) 시각과 서버 수신 시각을 구분해서 보여준다. 이전 집계/상세 없음, 로딩, 재시도 가능한 조회 실패, 50건 초과를 각각 표시한다. 기존 집계 JSON 내려받기에는 개인 상세를 포함하지 않는다.

서버는 su12ng/DASHBOARD_READ만 상세 조회를 허용한다. 프론트에서는 검증된 계정만 @username으로 표시하며 익명·인증 만료·탈퇴는 계정 확인 불가로 표시한다. 상세 정보는 7일 보관, 탈퇴 시 본인 상세 삭제.

웹 API 요청 시작에 허용된 메뉴 코드/시각/세션을 캡처한다. 다른 메뉴 이동 뒤 실패해도 최초 화면을 유지한다. 보고 지연 중 계정이 바뀌면 익명으로 보내며 새 계정 토큰을 빌리지 않는다. 수집 전용 fetch는 refresh/logout/재귀 오류 보고를 하지 않는다. member 수집 401/403/404일 때만 같은 UUID로 익명 fallback한다. 토큰은 Authorization 헤더 외에 보관/본문 전송하지 않으며, 원래 요청 본문·검색어·raw URL·프로필/식당 ID를 기록하지 않는다.

검증: 오류 수집·세션·화면·관리자 상세 6 suites/74 tests 통과, 프로덕션 빌드 성공. 최종 전체 테스트/배포 상태는 PR 확인. 서버 V54 먼저 반영한 뒤 웹을 배포해야 한다. 앱의 계정/화면 기록은 신규 앱 빌드 이후 수집 가능하다. 과거 기록에 소급 적용하지 않는다.
