운영 공통 메뉴 · 마케팅 스튜디오 UX

관련 Issue: https://github.com/Yusungyong/plateService/issues/52
적용 범위: 운영 공통 탐색과 마케팅 운영. 기존 상세 업무 화면·백엔드 API 계약은 유지.

공통 탐색
- 상단/사이드바 메뉴 찾기: 이름뿐 아니라 회원·제작물·오류 등 작업 단어로 검색.
- Ctrl+K 또는 Cmd+K, Escape, 키보드 포커스 순환 지원.
- 한눈에 보기 / 사람과 콘텐츠 / 매장과 고객지원 / 개발과 점검 4개 묶음.
- 최대 5개 메뉴 고정. 브라우저에 메뉴 경로만 계정별 저장하며 현재 권한으로 재필터링.
- 모바일 메뉴에 Escape 닫기·포커스 복귀. 운영 화면과 공개 홈 접근 유지.
- 중복 바로가기 나열은 제거하고 운영 점검 기록은 본문 아래에서 필요할 때 펼침.

마케팅
- 오늘 / 제작물 / 게시 / 이력 중심. 캠페인·작업예약·성과는 추가 관리에 보존.
- 다음 작업 안내와 클릭 가능한 4단계 흐름. 실제 조회 범위의 집계만 표시.
- 제작물 보관함은 날짜·상태·캠페인·ID 검색/필터, 날짜순 탐색.
- 선택한 제작물만 상세 조회. 목록 전체 썸네일 요청을 추가하지 않음.
- A/B 개별 확인과 나란히 비교, 변경·검토 이력 직접 열기.
- 게시 문구·대본·연결 설정·사용량은 펼침으로 확인. 대본은 실제 길이를 표시.
- 기존 tab URL, 권한, 버전 검사, 변경 확인, 미확인 요청 복구, 게시 안전 조건 유지.
- 과거 이미지 버전 비교나 실제 영상 생성 기능은 추가하지 않음.

검증
CI=true npm test -- --watchAll=false --watchman=false --runInBand
npm run build
PLATE_PLAYWRIGHT_MODULE=<설치된-playwright/index.mjs> node scripts/admin-ux-browser.mjs --base-url http://127.0.0.1:4186 --output <검증출력경로>
브라우저 검증은 합성 관리자·제작물과 API 가로채기를 사용한다. 실제 회원/인증 파일을 읽지 않으며 외부 요청·변경 API를 차단한다.
화면 예시는 UI 검증용 데이터이며 운영 실적 증거가 아니다.
