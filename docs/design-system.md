# 접시 공통 화면 정비 · 2026-09-16

## 메뉴와 화면 목적 정리

공개 질문·답변 / 비공개 1:1 문의로 공개 범위를 메뉴에 명시합니다. 점주 메뉴는 매장 운영 현황 / 식당 입점 신청 / 입점 신청 현황 / 내 매장 관리로 통일하고, 관리자 승인 메뉴는 입점 신청 심사로 표시합니다. 신청 상세의 주 제목은 항상 입점 신청 상세이며 매장명·심사 상태는 별도로 표시합니다.

공통 영역명은 작은 안내로, 각 페이지의 실제 제목은 유일한 h1으로 표시합니다. 일반 페이지와 로그인은 브라우저 탭 제목도 화면에 맞춰 갱신합니다. 로그인 소개와 다음 단계 안내는 일반 이용자·식당 담당자·운영자에 따라 다르며, 점주 영역의 수동 로그인 버튼도 복귀 경로를 전달합니다. 계정 권한과 API 계약은 변경하지 않습니다.

홈페이지의 아이보리 배경, 코랄 포인트, 짙은 본문, 둥근 카드·버튼을 서비스 전체에 적용합니다. 작은 글자의 버튼·링크는 가독성을 위해 코랄보다 짙은 `#ba4522`를 사용합니다.

## 공통 코드

- `src/components/PlateBrand.js`: 접시 아이콘과 홈 이동 링크, 공통 하단 안내.
- `src/styles/brand.css`: 공통 색상, 폼·카드·탐색·로그인·관리자 스타일 및 모바일 대응.
- `AppShell`: 고객지원·회원가입·점주 페이지 상단 홈, 본문 바로가기, 하단 안내.
- `AdminShell`: 사이드바와 상단 홈 링크. 모바일에서 사이드바를 열지 않아도 홈으로 이동 가능.
- `Login`: 브랜드 홈 링크와 간결한 모바일 소개. 인증·권한·로그인 후 이동은 기존 로직 유지.
- `NotFound`, `AppErrorBoundary`: 잘못된 주소와 화면 오류에도 홈 복귀 제공.

## 약관 원본 보존

`scripts/legal/lib.cjs`는 열람용 HTML에서 상단 탐색 부분만 최신 홈 링크로 교체합니다. 현재 안내와 버전 열람 화면, 버전 목록, 문서 없음 화면에 적용합니다. 약관 본문·시행일·버전·확인 주석은 변경하지 않습니다.

`content/legal/artifacts`와 `/legal/documents/*/*.html` 다운로드 보관본은 바이트와 해시를 그대로 유지합니다. 다운로드 보관본 자체의 과거 탐색 링크는 역사적 원본의 일부입니다. 매니페스트의 SHA-256은 다운로드 보관본을 검증하는 값이며 열람 페이지 HTML 전체의 해시가 아닙니다. JavaScript 없이도 전문과 홈 링크를 제공하며, 미게시 문서 분리를 유지합니다.

## 검증과 미리보기

`npm start` 후 `/`, `/faq`, `/qna`, `/signup`, `/login`, `/business/signup`, `/admin/dashboard`, `/terms-of-service`, `/privacy-policy`에서 확인합니다. 관리자 실제 데이터는 유효한 계정과 백엔드가 필요합니다. UI 검증용 브라우저 세션은 별도 테스트 토큰·네트워크 차단/고정 응답을 사용하며 실서비스 계정을 변경하지 않습니다.

`npm test -- --watchAll=false --runInBand`, `npm run test:legal`, `npm run build`로 기존 업무 흐름, 새 홈 복귀, 문서 불변성과 빌드를 검증합니다. 운영 배포는 별도입니다.

## 식당 입점 신청의 로그인 선행

식당 입점 신청은 로그인한 회원만 작성·제출합니다. `/business/signup` 직접 진입과 기존 `/business/stores/new` 주소 모두 인증 보호를 받습니다. 신규 회원은 일반 회원가입 후 로그인하며, 로그인·회원가입 사이에 신청 목적지를 유지합니다. 입점 신청서의 계정 생성 단계와 익명 가입·신청 API 호출을 제거하고, 로그인 토큰으로 `/api/owner/store-applications`에 제출합니다. 신청 자격에는 점주 승인 권한이 필요하지 않으며 승인된 매장 관리 권한은 기존대로 유지합니다.

이는 홈페이지 흐름 변경입니다. 백엔드의 기존 공개 `/api/owner/signup-applications` 엔드포인트 폐쇄 여부는 별도 서버 작업으로 확인해야 합니다.
