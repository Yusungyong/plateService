# 제철 관리 화면 구분

Backend: Yusungyong/plateAppServer#52. Admin: #3.

`/admin/seasonal-foods`: 가져오기 없이 모든 원본을 바로 조회. 소개·선택/보관/주의 안내와 대표/모바일 이미지를 저장하면 앱 목록/상세에 반영된다. 제철 기간·분류·출처·공개 상태는 이번 편집 범위에서 유지한다.

`/admin/seasonal-curations`: 추천 식재료를 선택하고 헤드라인/추천 문구/월/절기/노출기간/순서를 작성해 발행하면 앱 상단 PICK에 반영된다. 전용 이미지를 비우면 원본 이미지를 사용한다. 전용 이미지 수정은 원본을 덮어쓰지 않는다. 발행 해제하면 초안으로 돌아간다.

최대 3개. 현재 제철·공개 조건을 충족하는 발행/예약 시작 항목만 노출한다. 식재료를 삭제하거나 중복 생성하지 않는다. 기존 가져온 초안도 추천 식재료 연결을 유지한다.

백엔드 배포 → 관리자 main 자동 배포 순서. 앱은 로컬 소스 변경이며 앱스토어 배포는 별도이다.
